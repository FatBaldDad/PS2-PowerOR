# Safety and Limitations

PS2-PowerOR is experimental.

PS2-PowerOR is not a finished product.

PS2-PowerOR is not a guaranteed safe USB-C power solution.

PS2-PowerOR is not a universal PS2 power mod.

PS2-PowerOR should not be installed by beginners.

Incorrect power modifications can damage hardware.

No public installation method is currently provided.

Detailed safety validation remains private until the project is more mature.
