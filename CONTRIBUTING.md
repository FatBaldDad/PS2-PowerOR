# Contributing to PS2-PowerOR (Public Repository)

Thank you for your interest in PS2-PowerOR.

This repository is announcement-only and documentation-focused while active development remains private.

## Contributions Currently Welcome

- Public feedback
- Compatibility observations
- Documentation corrections
- General safety observations
- Research references that are already public
- General feature suggestions

## Not Currently Accepted

- Hardware design pull requests
- PCB layout pull requests
- Fork-based development
- Clone hardware designs
- Manufacturing files
- Installation method submissions
- Test data submissions that expose private methods
- Productized derivatives
- Alternative implementations based on private FBD work

If you are unsure whether a submission is appropriate, open an issue first.
